# minikv — инструкции для AI-агентов

- Без внешних зависимостей в рантайме: только стандартная библиотека. redis-py — только для тестов.
- Тесты: `pytest`; линтер: `ruff check src tests scripts && ruff format --check src tests scripts`.
- Новая команда — функция с `@command(name, arity, write=...)` в `commands.py`. Арность как в Redis
  (с учётом имени команды; отрицательная — минимум).
- Команда записи, зависящая от текущего времени, должна вызывать `ctx.rewrite_as(...)` с
  абсолютным временем (`PXAT`, `PEXPIREAT`), чтобы AOF проигрывался детерминированно.
- Изменение коллекции на месте (deque/dict/set) — обязательно `keyspace.touch_modified(key)`,
  иначе сломаются WATCH и LRU. Пустые коллекции удаляются.
- Поведение сверять с документацией Redis и проверять через redis-py (RESP2 и RESP3).
